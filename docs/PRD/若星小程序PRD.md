## 一、产品概述

### 1.1 产品定义

若星小程序是若星团队与学员之间的效能工具与陪伴工具。以「课程、活动、内容、会员、商城」为载体，帮助学员有序参与课程与活动、沉淀学习与实践记录；同时帮助团队高效完成报名、收款、资料发布、内容管理、学员陪伴。

### 1.2 产品边界

- 不是营销工具；不做开放 UGC 社区；不做自有电商交易（商城跳转第三方）；不制造焦虑。

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 访客 | 未登录/未报名，可浏览课程、活动、内容 |
| 学员 | 已报名课程/活动，可进入学习区、打卡、查看记录 |
| 基础会员 / 深度会员 / 共创伙伴 | 会员层级，享有对应权益 |
| 若星团队成员 | 运营人员，负责课程、活动、内容、学员陪伴 |
| 团队管理员 | 更高权限，全面管理后台 |

### 3.11 微信支付

**支付场景**：

| 场景 | 金额来源 | 说明 |
|------|----------|------|
| 课程报名 | 课程价格（后台配置） | 确认报名后支付 |
| 活动报名 | 活动单价 × 人数（动态计算） | 带孩子免费、邀请码奖励 |
| 会员开通/续费 | 会员价格（后台配置） | — |

**支付流程（业务层）**：

1. 填写报名表单并提交；
2. 系统创建订单（生成订单号，记录内容、金额、学员）；
3. 发起微信支付（小程序内支付）；
4. 支付成功后订单状态更新为「已支付」；
5. 进入报名成功页，展示入群指引。

**订单字段**：订单号、学员、报名内容（课程/活动/会员）、金额、支付时间、状态。

**金额计算规则**：

- 课程：固定价格（后台配置）。
- 活动：单价 × 人数，实时计算实付金额；带孩子免费；邀请码双方获礼不影响金额。
- 会员：按层级对应价格。

**退款流程**：

- 用户提交退款申请（前台/后台）；
- 后台订单管理中标为「退款申请中」，处理前先电话沟通；
- 处理完成后订单状态更新为「已退款」。

**前后端关联**：

- 前台：报名表单 → 支付 → 报名成功；我的订单（查看支付状态）。
- 后台：订单管理（订单列表、按类型/退款筛选、退款处理）。

**可配置项**：各场景价格、是否支持退款、退款规则。

### 4.2 拾光读书

**课程概况**：线上共读课，示例 8 周，每周相聚直播（腾讯会议），**直播无回放**；推荐制报名（仅被推荐会员可见可报名）。

| 维度 | 内容 |

## 八、功能详述与开发说明

> 本节为开发人员补充每个功能点的具体功能描述、交互流程与实现逻辑说明。数值项均按「可配置参数」处理。

### 8.1 前端核心交互流程

#### 8.1.1 课程报名与支付流程

```
浏览课程（成长页/首页）→ 课程详情 → 点击「报名」
  ├─ 未登录 → 引导登录后返回
  ├─ 读书会 → 校验推荐资格（无资格不可报名）
  └─ 已报名 → 按钮禁用「您已报名」
→ 填写报名表单（字段由报名配置动态渲染）
→ 提交校验（必填/格式）
→ 创建订单（金额 = 课程价格）
→ 发起微信支付
  ├─ 支付成功 → 订单「已支付」→ 报名成功页（入群指引）→ 查看我的课程
  └─ 失败/取消 → 订单保持「待支付」，可重新支付
```

**逻辑说明**：报名状态判定优先级为「往期（已结束）> 已报名 > 截止/满员 > 可报名」；表单必填未填则提示并中止；支付成功回调后更新订单状态再进入成功页。

**开发说明**：课程详情需返回课程状态与报名入口；报名表单支持动态字段（基础字段开关/扩展字段/自定义字段）；读书会需在课程列表与详情做可见性过滤 + 报名前推荐资格校验。

#### 8.1.2 活动报名流程

```
活动列表/详情 → 报名
  ├─ 满员/截止 → 报名关闭（禁用）
  └─ 可报名 → 表单（参加人数/是否带孩子/邀请码）
→ 人数/带孩子变化 → 实时计算金额（单价×人数，孩子免费）
→ 邀请码校验 → 双方获礼
→ 支付 → 报名成功 → 我的活动（待赴约）
```

**开发说明**：金额实时联动（监听人数与带孩子字段变化重算实付金额与按钮文案）；邀请码由后端校验有效性并记录邀请关系与奖励；满员后自动关闭报名入口。

#### 8.1.3 学习流程

```
我的 → 我的课程 → 选择课程 → 学习区（分区切换）
课程概要 → 课节时间轴 → 已开课节 → 课节页
课节页 → 观看/相聚 / 阅读 / 导读摘要 / 金句 / 作业 / 大家的实践
课节页「腾讯会议」→ 直接跳转到对应腾讯会议室
课节页「记录实践」→ 打卡
```

**逻辑说明**：课节按配置时间自动解锁，未开放显示「将于 X 开启」不可进入；课节内容按课程类型差异化（回放/无回放、阅读资源是否定时开放）；线上课程在课节页展示腾讯会议入口，点击跳转对应会议室（会议号/链接由后台配置）。

**开发说明**：学习区分区按课程类型配置渲染；课节状态（已结束/进行中/未开放）由开放时间计算；腾讯会议跳转通过会议号/链接调起腾讯会议（小程序内跳转或调起腾讯会议应用），未开课时隐藏或置灰会议入口。

#### 8.1.4 打卡流程

```
打卡入口 → 打卡提交页
→ 选择上传类型（图片≤N张 / 文字 / 视频≤M分钟）
→ 选择关联课程（联动标签集渲染）
→ 选择标签（必选，未选中止）
→ 提交 → 分享面板（好友/群聊/分享图）
```

**开发说明**：上传类型切换动态改变输入区（图片数量/视频时长限制由配置下发）；标签集随关联课程动态渲染，切换课程清空已选标签；提交前校验标签必选，成功后弹分享面板。

#### 8.1.5 内容浏览流程

```
导读摘要：课节 → 导读摘要详情（下载思维导图/留言）
故事：学习区故事 → 故事列表（标签筛选）→ 故事详情（下载/留言）
每日内容：学习区日日新生/金句/食谱 → 每日内容流（定时解锁）
工具表单：学习区资料 → 下载
```

**开发说明**：每日内容按解锁时间控制可见性，未到显示「明日解锁」；留言空内容不可提交、提交后置顶显示。

#### 8.1.6 商城跳转流程

```
商城 → 分类筛选 → 商品点击 → 弹「即将离开若星」面板 → 确认打开第三方小程序
礼品订制 → 联系客服 → 客服会话
```

#### 8.1.7 会员与成长流程

```
会员入口 → 会员中心（身份/权益/层级）
我的 → 我的成长 → 个人星图 + 成长时间线（里程碑由成长事件自动生成）
```

#### 8.1.8 个人中心流程

```
我的 → 编辑资料（头像/昵称，昵称长度校验）
我的 → 我的订单 → 订单详情 / 退款申请
我的 → 上课提醒（开课前 N 小时自动弹出，可关闭）
```
