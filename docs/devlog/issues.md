## 模板参考

```markdown
## ISSUE-001：[简短描述问题名称]

### 发现时间
YYYY-MM-DD

### 现象
详细描述具体错误信息、日志输出或异常表现。

### 原因
深入分析导致该问题的根本原因（如微信 API 特殊限制、跨域配置、Prisma 连接池耗尽等）。

### 解决方案
详细说明代码修改或配置调整方案。

### 影响范围
受影响的模块或用户群体。

### 是否彻底解决
- [x] 是
- [ ] 否

### 后续注意事项
防止再次出现类似问题的预防措施。
```
