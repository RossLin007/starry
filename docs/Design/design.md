# 若星空间 (Starry Space) 视觉识别系统设计规范 (VI Design System)

> **版本**：V1.0  
> **制定日期**：2026-08  
> **基准来源**：提炼自《若星 · 视觉识别系统 VI SYSTEM》（`docs/Design/VI/index.html`）、《DESIGN.MD》及 `prototype-v3` 原型设计规范。  
> **核心原则**：清净、温暖、有秩序、有觉知。像一页排版讲究的杂志，克制温润地陪伴生活。

---

## 01 品牌内核 (Brand Core)

### 1.1 品牌含义 (Meaning)
> **“每一个心灵觉醒的人都像一颗星星。一颗星星可能不耀眼，但十颗、五十颗、一百颗，就能在黑夜中形成光。”**

### 1.2 品牌主张 (Mission)
通过饮食、空间、说话、家庭关系、读书、茶、运动、审美等日常生活方式，帮助现代人回到更健康、更清明、更有觉知、更有爱的生活状态。

### 1.3 核心视觉双世界概念 (Concept)
- **白昼世界 · 纸上日常（约 90% 场景）**：
  - 应用范围：课程、打卡、活动、物料印刷、日常界面；
  - 视觉特征：近白纸底上的日常生活，安静、明亮、有序，如同翻阅一页讲究的纸质杂志。
- **星夜世界 · 夜里微光（约 10% 场景）**：
  - 应用范围：星愿会员、成长星图、年报、仪式感物料、封面；
  - 视觉特征：深邃夜空蓝上的微光时刻，代表若星的精神意象，只在“向内看”和深度陪伴的时刻出现。

### 1.4 品牌关键词 → 视觉翻译 (Translation)

| 品牌语言 | 视觉语言表达 |
| :--- | :--- |
| **清净** | 大量留白、信息克制、一次只说一件事、拒绝多余装饰 |
| **温暖** | 纸感底色（`#FEFFFD`）、柔和圆角与边界、暖调自然光 |
| **有秩序** | 严谨网格与节奏、时间轴式结构、清晰的大纲层级 |
| **有觉知** | 慢动效、呼吸感节奏、不催促、不制造紧迫感 |
| **星星与光** | 四角星点 `✦`、夜空蓝微光时刻、极细微光渐变与金色点缀 |
| **日常修行** | 真实生活摄影、手作质感、不过度精修、原样呈现 |

## 02 标识系统 (Logo System)

若星标识由「四角星标 ✦」与「中英文标准字」构成。整体风格安静、纤细、克制，不喧哗。

### 2.1 标识构成 (Construction)
1. **星标 (Star Mark)**：四角星（非五角星），上下角略长，形态纤细安静。标准色为若星绿，星夜场景使用星光金。
2. **标准字竖排锁定 (Primary Lockup)**：主标识形式，上方星标，下方中文「若星空间」，副标题英文「STARRY SPACE」。
3. **横排组合 (Horizontal Lockup)**：左侧星标/右侧文字，用于页眉、信封、横幅等狭长空间。

| 标识元素 | 规范参数 |
| :--- | :--- |
| **星标 ✦** | 四角对称微拉伸星形。白昼场景用若星绿 `#019A4A`，星夜场景用星光金 `#F0D9A8` |
| **中文标准字** | `PingFang SC Semibold`，字距 `+32%`，若星绿 |
| **英文品牌字** | `STARRY SPACE`（全大写），字距 `+24%`，灰褐 `#4F5345`，作为装饰性品牌字 |
| **组合关系** | 竖排为主标识；横排为辅助；星标可单独作为品牌图形记号使用 |

### 2.2 反白与深色应用规则 (Reversed)
- **夜空蓝底上**：标准字反白（星夜米白 `#E9E4D8`），星标使用星光金 `#F0D9A8`；
- **若星绿底上**：标准字纯白 `#FFFFFF`，英文副标题使用 `70%` 透明度白色；
- **摄影图底上**：仅在浅色、低干扰区域放置反白标识，禁止在深色复杂底图上直接压字。

### 2.3 安全空间与最小尺寸 (Clear Space & Minimum Size)
- **安全空间**：以星标高度（`1✦`）为度量单位，标识四周必须保留不小于 `1✦` 的净空，净空内严禁出现任何文字、图形或图片边缘。
- **最小尺寸规范**：
  - 数字端（屏幕）：中文标准字最小 `16px`；
  - 印刷端：中文标准字最小高度 `5mm`（此时英文副标题可省略）；
  - 星标单独使用：屏幕端最小 `16px`，印刷端最小 `4mm`。

### 2.4 印章标识 (Seal)
- **形态**：朱文印章「若星」，楷体，带外框，微倾 `-4°`。
- **颜色**：绯红 `#B04A33`。
- **使用场景**：借鉴中式手账钤印，**仅用于**精选学员故事落款、共创伙伴专区、结业证书与感谢卡，代表“被若星认真盖章确认过的人和事”。
- **限制**：这是全品牌**唯一允许以绯红做装饰**的场景，尺寸严禁放大超过 `16mm`。

### 2.5 标识错误用法禁忌 (Don'ts)
- ✕ 严禁改变标准字颜色（如染成绯红或黄色）；
- ✕ 严禁压缩字距（破坏宽松呼吸感）；
- ✕ 严禁倾斜、拉伸、压扁或变形；
- ✕ 严禁添加投影、描边、发光或立体特效；
- ✕ 严禁将四角星替换为五角星或其他星形；
- ✕ 严禁随意改变星标与中英文标准字的相对位置关系。

## 03 色彩系统 (Color System)

以 prototype-v3「V3 活力绿」为基准：鲜绿行动色 + 近白纸底 + 高对比文字。白昼与星夜两个世界各自成色，互不混杂。

### 3.1 白昼世界色板 (Day Palette - 约 90% 场景)

| 色彩名称 | HEX / RGB 代码 | 用途与对比度 |
| :--- | :--- | :--- |
| **若星绿 (Primary)** | `#019A4A` / `rgb(1,154,74)` | **品牌主色 · 唯一行动色**：标识、关键标题、主操作按钮、行动链接、序号圆 |
| **深林绿 (Ink)** | `#16300F` | **主要阅读文字**（对纸白对比度 14.0:1） |
| **橄榄绿 (Tea)** | `#38502E` | 辅助文字、眉题、章节引导（8.7:1） |
| **橄榄黄绿 (Olive)** | `#7BAF42` | 点缀过渡、插画与影像辅助线条 |
| **纸白 (Paper)** | `#FEFFFD` | 全局页面与印刷底色，近纯白、通透温润 |
| **浅芽绿 (Bud)** | `#F0F8E4` | 标签背景、温馨提示条背景、浅色容器块 |
| **暖米灰 (Rice)** | `#F0F2E9` | 分隔线、卡片描边、占位底色 |
| **灰褐 (Ash)** | `#4F5345` | 次要文字、英文小字、元数据说明（7.7:1） |
| **绯红 (Crimson)** | `#B04A33` | 极少量：必要警示文字与朱文印章，不作装饰面 |

### 3.2 星夜世界色板 (Night Palette - 约 10% 场景)

| 色彩名称 | HEX 代码 | 用途与说明 |
| :--- | :--- | :--- |
| **夜空蓝 (Night)** | `#1F2A44` | 星夜底色：星愿会员、成长星图、年度回顾、封面 |
| **雾蓝 (Mist)** | `#3D4E73` | 夜空蓝上的层级过渡、次级面板容器背景 |
| **星光金 (Star)** | `#F0D9A8` | 星夜点亮元素：星标、星座星点、关键金句、高光 |
| **星夜米白 (Cream)** | `#E9E4D8` | 星夜世界文字正文（对夜空蓝对比度 9.6:1） |

### 3.3 场景色彩使用比例 (Ratio)
- **白昼世界（90% 场景）**：
  `纸白 70%` + `深林绿 15%` + `橄榄绿 10%` + `若星绿 5%`
- **星夜世界（10% 场景）**：
  `夜空蓝 75%` + `雾蓝 10%` + `星光金 10%` + `米白 5%`

### 3.4 核心色彩规则 (Rules)
1. **一屏一处绿**：若星绿是全品牌唯一行动色，一屏内原则上只出现在核心行动点上（序号圆等功能性重复除外）；
2. **两界不混杂**：白昼界面绝不出现大块夜空蓝底；星夜界面不使用纯白大底（使用雾蓝作分层）；
3. **安全对比度**：所有文本与背景对比度必须 `≥ 4.5:1`；
4. **状态色规范**：成功状态采用若星绿系；危险/删除操作仅用绯红文字提示，不使用刺眼大红底按钮；
5. **绝对禁用**：禁用高饱和荧光色、电商大红大橙、纯黑 `#000000` 以及炫光渐变按钮。

## 04 字体系统 (Typography)

全品牌统一使用系统级字体族，不加载沉重网络字体。层级依靠字重与字号严格区分，不靠字体花样。

### 4.1 字体选型与回退
- **全局正文与界面**：`"PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`
- **标题与强调**：`PingFang SC Medium / Semibold`
- **装饰与寄语**：系统楷体 `"Kaiti SC", "STKaiti", "KaiTi", "PingFang SC", sans-serif`（极少量：导师寄语、心得引用、印章）

### 4.2 字号阶梯规范 (Type Scale)

| 层级角色 | 字号 / 字重 | 行高 | 应用场景 |
| :--- | :--- | :--- | :--- |
| **引言金句** | `24pt / 48rpx` Medium | `1.6` | 页面顶部核心引言、每日星语核心句 |
| **页面主标题** | `20pt / 40rpx` Semibold | `1.5` | 课程主标题、活动大标题、营期名称 |
| **章节/栏目标题** | `18pt / 36rpx` Medium | `1.5` | 模块小标题、阶段分组名（若星绿） |
| **正文强调** | `16pt / 32rpx` Medium | `1.6` | 卡片主旨句、重点提醒、课节名称 |
| **正文 (Body)** | `15pt / 30rpx` Regular | `1.7` | 文章正文、课件内容、心得描述 |
| **辅助说明** | `13pt / 26rpx` Regular | `1.5` | 营期排期、地点、时间元数据（灰褐） |
| **微信息 (Micro)** | `12pt / 24rpx` Regular | `1.4` | 标签、分类角标（**全品牌最小字号**） |
| **楷体寄语** | `17-19pt` Regular | `2.0` | 主理人温润寄语、学员金句引用（每页限 1 处） |
| **中英双语栏目** | 中文 `18pt` + 英文 `12pt` | `1.5` | 栏目名 + 英文全大写（字距 `+18%` 灰褐） |

### 4.3 文字排版守则
- 中文正文字距统一 `+2%`，行高不小于 `1.6`；
- 长文段落之间**空一行**，严禁使用首行缩进；
- 数字与英文在中文语境中前后留出四分之一空格（如“共 8 节课”、“已亮 12 颗星”）；
- 同一行内严禁出现超过两种字重；英文仅用于栏目副标与品牌标识，操作界面使用纯正中文。

## 05 视觉符号系统 (Visual Symbols)

星点、签名分隔符、印章、序号圆与个人星图——若星的五大签名符号，限量克制使用。

### 5.1 五大核心符号
1. **四角星点 ✦**：
   - 品牌唯一图形符号；
   - 三档标准尺寸：`6pt`（行文微点缀）/ `12pt`（标识伴随）/ `32pt`（仪式高光）；
   - 严禁出现在输入框、表单控件和高密度信息表内。
2. **签名分隔符 (✦ ✦ ✦)**：
   - 三颗四角星点水平排列，间距舒展；
   - 仅用于大章节过渡与核心引言之后，作为若星的专属标点符号。
3. **朱文印章**：
   - 绯红 `#B04A33`，楷体，外框微倾；
   - 仅用于精选上墙故事、结营证书与主理人感谢卡落款。
4. **若星绿序号圆**：
   - `24–34px` 实心若星绿圆圈 + 居中白色数字；
   - 用于课节排期、操作步骤、物料清单；功能性重复不违反行动色克制原则。
5. **设计签名 · 个人星图 (Personal Star Map)**：
   - 视觉形态：夜空蓝画布上由极细金线相连的金色四角星；
   - 规则：成长不是冰冷的进度条，而是一片慢慢被点亮的星空（完成一门课亮一颗大星，累计 7 次打卡亮一颗小星）；
   - 星图**不标生硬数值坐标**，是一幅属于学员个人的温润画卷。

## 06 影像风格指南 (Photography)

若星的画面由真实生活摄影与留白排版构成，**不画低幼插画、不用商业图库摆拍图**。

### 6.1 四大影像原则
1. **真实**：若星空间实景、真实的饭菜器物、真实的桌面与书房；
2. **自然光**：上午或傍晚的柔和自然侧光，温润暖调；
3. **留白构图**：茶席的一角、书桌的局部优于全景铺满；
4. **人物抓拍**：多呈现手部整理动作、侧影、背影，严禁看镜头摆拍。

### 6.2 影像技术参数与裁剪比例
- **色调调整**：向纸白与若星绿靠拢，整体降低饱和度 `10–15%`，高光偏暖，允许自然的暗部与轻微过曝；
- **比例规范**：课程头图 `4:3`，活动海报/卡片 `1:1`，故事封面 `16:10`；
- **排版原则**：图片严禁添加浮夸滤镜边框，**严禁在图片上直接压大字**——文字一律置于图片下方的留白卡片区。

## 07 核心触点与应用系统 (Applications)

### 7.1 应用速查表

| 触点场景 | 标准规范要求 |
| :--- | :--- |
| **小程序头像** | 绿底白星（主用），正方形圆角容器内星标占画幅 `47%` |
| **社媒 / 微信头像** | 绿底白星；星夜主题活动期可切换为夜底金星 |
| **启动页 / 封面** | 星夜世界：夜空蓝底 + 微闪呼吸星点 + 竖排中英标准字 |
| **学员名片 / 邀请函** | 纸白底色、左上标准字、右下若星绿小星标、折痕打孔细节 |
| **结业证书 / 感谢卡** | 米白刚古纸质感、正文 15pt、右下落款盖朱文印章 |
| **实体物料印刷** | 选用未涂布米白特种纸（如大地纸/刚古纸），禁用刺眼高光铜版纸 |

## 08 品牌语调与文案规范 (Brand Voice)

VI 不只是图形与色彩，更是与学员对话的方式。**温暖而不煽情，清晰而不生硬，有指引而不说教——像一位安静的朋友在说话。**

### 8.1 场景文案对照表

| 业务场景 | 严禁使用 (✕) | 推荐使用 (✓) |
| :--- | :--- | :--- |
| **报名按钮** | “立即抢购”“马上报名”“限时秒杀” | **“报名课程”“我想参加”** |
| **报名成功** | “支付成功！恭喜发财” | **“已为你留好位置。”** |
| **课程满员** | “手慢了！名额已抢光” | **“本期已满，下一期正在准备中。”** |
| **会员到期** | “会员即将过期，立即续费享特权！” | **“你的会员将在 9 月底到期，随时欢迎回来。”** |
| **网络异常** | “网络错误 500，请重试” | **“刚才没有加载出来，再试一次吧。”** |
| **学习打卡** | “打卡赚积分！领大奖” | **“记录今天的微小实践。”** |

### 8.2 称谓与词汇法则
- 对用户一律称**“你”**，严禁用“亲”“宝子”“家人们”；
- 课程参与者称**“学员”**或**“同学”**，不用“客户”“买家”；
- 团队与学员的关系是**“陪伴”**，严禁用“转化”“私域运营”“跟进”；
- 拒绝互联网黑话（“赋能”“抓手”“闭环”“打法”），多用**“一起”“慢慢”“可以”“安顿”**。

## 09 品牌禁忌红线清单 (Red Lines)

任何页面、海报、功能模块与文案上线前，必须逐项对照以下禁忌红线：

- [ ] ✕ **严禁出现轮播 Banner 广告、功能金刚区宫格、弹窗广告与悬浮广告球**；
- [ ] ✕ **严禁制造焦虑**：不出现倒计时器、库存紧张红字、已抢 XX 件、XX 人正在拼团；
- [ ] ✕ **严禁营销裂变诱导**：不出现“分享给好友领红包”“砍价免费拿”；
- [ ] ✕ **严禁游戏化内卷机制**：不搞等级排行榜、连续签到断签惩罚；
- [ ] ✕ **严禁使用高饱和度亮色、大红大橙渐变按钮与重度阴影投影**；
- [ ] ✕ **严禁使用低幼表情包插画或夸张卡通 IP**；
- [ ] ✕ **星点与印章严格限量**，绝不为了装饰而满屏堆砌；
- [ ] ✦ **核心自检标准**：
  1. *“这一屏 / 这一页，能不能再少一样东西？”*
  2. *“遮住 Logo 之后，这件作品是否仍然能让人一眼认出是若星，而不是市面上的任何一个普通电商或知识付费软件？”*
