01

品牌内核

Brand Core

VI 系统的一切规则，都从品牌的发心推导而来。先理解"为什么"，再执行"怎么做"。

品牌含义Meaning

每一个心灵觉醒的人都像一颗星星。
一颗星星可能不耀眼，但十颗、五十颗、一百颗，
就能在黑夜中形成光。

品牌主张Mission

通过饮食、空间、说话、家庭关系、读书、茶、运动、审美等日常生活方式，帮助现代人回到更健康、更清明、更有觉知、更有爱的生活状态。

核心视觉概念Concept

白昼世界 · 纸上日常

约 90% 的视觉场景。近白纸底上的日常生活：课程、打卡、活动、物料印刷。安静、明亮、有序，像一页排版讲究的杂志。

星夜世界 · 夜里微光

约 10% 的视觉场景。深邃夜空蓝上的微光时刻：会员、成长、年报、仪式感物料。若星的精神意象，只在"向内看"的时刻出现。

品牌关键词 → 视觉翻译Translation

品牌语言视觉语言
清净大量留白、信息克制、一次只说一件事
温暖纸感底色、柔和圆角与边界、暖光点缀
有秩序严谨网格与节奏、时间轴式结构
有觉知慢动效、呼吸感、不催促
星星与光四角星点 ✦、夜空蓝时刻、微光渐变
日常修行真实生活摄影、手作质感、不过度精修

色彩规则Rules

  • 若星绿是全品牌唯一行动色：一屏内只出现在主要行动点上（序号圆等功能性重复除外）
  • 两个世界不混色：白昼界面不出现夜空蓝色块；星夜界面不使用纸白大底（用雾蓝分层）
  • 成功状态用若星绿系；危险操作只用绯红文字，不用红底按钮
  • 禁用：高饱和色、荧光色、电商红橙色、纯黑 #000、渐变按钮
  • 所有文字与底色对比度 ≥ 4.5:1；装饰性星点不承担信息传达

视觉符号

Symbols

星点、印章、序号圆、个人星图——若星的四个签名符号。限量使用，不泛滥。

星点 ✦
唯一装饰符号。三档尺寸：6pt 点缀 / 12pt 标识 / 32pt 仪式时刻。不出现在按钮、表单、信息密集处。
✦ ✦ ✦

三颗星点横向排列，仅用于章节过渡与引言之后。这是若星的标点符号。

朱文印章
绯红、楷体、微倾。仅用于精选故事、共创伙伴与证书的落款。
1  2  3
若星绿序号圆
24–34px 实心圆 + 白字。用于步骤、流程、清单。功能性重复不违反"一屏一处绿"规则。

设计签名 · 个人星图Signature

你已经在若星点亮了 12 颗星。
  • 成长不是进度条，是一片慢慢点亮的星空：完成一门课亮一颗大星，累计七次实践亮一颗小星
  • 星图不标数值、不做精确坐标——它是一幅渐渐变亮的画，不是数据图表
  • 星点之间以极细金线相连，逐渐形成属于这个人的星座
  • 全品牌仅此一处浓墨重彩，其余界面保持安静

影像风格

Photography

若星的画面由真实摄影与排版构成，不画装饰插画、不用图库摆拍。

真实 · 若星空间实景与真实的饭菜器物
自然光 · 上午或傍晚侧光，暖调
留白构图 · 桌面茶席的"一角"优于全景
人物 · 多是手、侧影、背影，不看镜头摆拍

影像规则Rules

  • 色调向纸白与若星绿靠拢，降饱和 10–15%，高光偏暖，允许轻微过曝与阴影
  • 图片比例：课程头图 4:3，活动卡片 1:1，故事头图 16:10
  • 图片不加滤镜边框、不加文字压图——文字永远在图下方留白处
  • 学员打卡照片原样呈现，不做美化模板

品牌语调

Voice

VI 不只是图形。温暖而不煽情，清晰而不生硬，有指引而不说教——像一位安静的朋友在说话。

  • 不说"赋能""打造""爆款"，说"一起""慢慢""可以"

09

品牌禁忌

Red Lines

任何物料、页面、文案交付前，逐条对照。守住这些线，若星就还是若星。

  • 不出现轮播 Banner、功能宫格、弹窗广告、浮标
  • 不出现倒计时、库存紧张、已抢 XX 件、XX 人正在看
  • 不出现积分、金币、排行榜、签到日历、连续打卡奖励徽章
  • 不出现裂变引导："分享给好友""邀请有礼""砍价"
  • 不使用高饱和色、渐变色块按钮、投影卡片
  • 不使用表情包式插画、夸张 IP 形象
  • 星点与印章限量使用，不泛滥
  • 任何新设计先问：这一屏 / 这一页，能不能再少一样东西？
  • 遮住标识后，这件物料是否仍然像若星，而不是任何一个电商 / 教育品牌？
