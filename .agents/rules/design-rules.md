# 若星空间 (Starry Space) - 视觉设计与品牌交互规则 (Design Rules)

> 本文件是若星空间项目所有 UI 开发、页面交互、文案撰写与视觉实现的工程规则。
> 所有 Agent 在新增或修改小程序、管理后台页面或文案时，必须严格遵守本规范。

---

## 1. 核心视觉理念：纸上日常，夜里微光

项目严格区分并按比例应用“双世界”视觉：

- **白昼世界（约 90% 的场景）**：
  - 适用：首页、课程、活动、打卡墙、好物商城、物料；
  - 视觉特征：近白纸底（`#FEFFFD`）上的温润生活，安静、明亮、有序，如同翻阅一页讲究的纸质杂志。
- **星夜世界（约 10% 的场景）**：
  - 适用：星愿会员、成长星图、年度回顾、仪式感封面；
  - 视觉特征：深邃夜空蓝（`#1F2A44`）底色上的微光时刻，金色星点与微光渐变，只在“向内看”时出现。

---

## 2. 核心色板与色彩规则

### 白昼世界主色板
- **若星绿 (`#019A4A` / `rgb(1,154,74)`)**：全品牌**唯一行动色**（主按钮、关键标题、行动链接、序号圆）；
- **深林绿 (`#16300F`)**：主要正文阅读文字（对纸白对比度 14:1）；
- **橄榄绿 (`#38502E`)**：辅助文字、眉题、章节小标题；
- **纸白 (`#FEFFFD`)**：全局页面与卡片温润白底；
- **浅芽绿 (`#F0F8E4`)**：标签底色、提示条浅底；
- **暖米灰 (`#F0F2E9`)**：分隔线、卡片描边、占位底；
- **灰褐 (`#4F5345`)**：次要文字、英文副标题；
- **绯红 (`#B04A33`)**：极少量，仅用于朱文印章与必要警示。

### 星夜世界色板
- **夜空蓝 (`#1F2A44`)**：星夜世界大底；
- **雾蓝 (`#3D4E73`)**：夜空蓝上的层级过渡面板；
- **星光金 (`#F0D9A8`)**：星标、星座点亮、关键金句；
- **星夜米白 (`#E9E4D8`)**：星夜正文字色。

### 强制色彩纪律
1. **一屏一处绿**：若星绿是唯一行动色，除序号圆外，一屏内原则上只出现一处若星绿主行动点；
2. **两界不混杂**：白昼界面不出现大块夜空蓝底；星夜界面不使用纯白大底；
3. **对比度达标**：所有文字与背景对比度必须 `≥ 4.5:1`；
4. **状态色规范**：成功态用若星绿系；危险/删除操作只用绯红文字，严禁使用大红底按钮；
5. **绝对禁用**：禁用高饱和荧光色、电商大红大橙、纯黑 `#000000` 以及炫光渐变按钮。

---

## 3. 字体排印与标点

- **全局字体**：`"PingFang SC", "Noto Sans SC", -apple-system, sans-serif`（不加载网络字体，以字重区分层级）；
- **寄语/印章**：系统楷体（`"Kaiti SC", "STKaiti", "KaiTi", serif`，每页至多一处）；
- **字号阶梯**：引言 24pt、页标题 20pt、节标题 18pt、正文强调 16pt、正文 15pt、辅助 13pt、微信息 12pt（全品牌最小字号）；
- **排版守则**：中文正文字间距 `+2%`，行高 `≥ 1.6`；长文段间空一行，严禁首行缩进；数字与英文在中文语境中前后留出空格。

---

## 4. 专属签名符号

1. **四角星标 (`✦`)**：品牌唯一图形符号（严禁使用五角星）；
2. **签名分隔符 (`✦ ✦ ✦`)**：三颗星点横向排列，仅用于大章节过渡与核心引言之后；
3. **朱文印章 (`若星`)**：绯红、楷体、微倾 `-4°`，仅用于精选上墙故事、证书与感谢卡落款；
4. **若星绿序号圆**：实心绿底白字圆圈，用于步骤、排期、流程。

---

## 5. 品牌语调与文案规范

**温暖而不煽情，清晰而不生硬，有指引而不说教——像一位安静的朋友在说话。**

| 业务场景 | 严禁使用 (✕) | 推荐使用 (✓) |
| :--- | :--- | :--- |
| **报名按钮** | “立即抢购”“马上报名”“限时秒杀” | **“报名课程”“我想参加”** |
| **报名成功** | “支付成功！恭喜发财” | **“已为你留好位置。”** |
| **课程满员** | “手慢了！名额已抢光” | **“本期已满，下一期正在准备中。”** |
| **会员到期** | “会员即将过期，立即续费享特权！” | **“你的会员将在 9 月底到期，随时欢迎回来。”** |
| **网络异常** | “网络错误 500，请重试” | **“刚才没有加载出来，再试一次吧。”** |
| **学习打卡** | “打卡赚积分！领大奖” | **“记录今天的微小实践。”** |

- 对用户一律称**“你”**，不用“亲”“宝子”“家人们”；
- 课程参与者称**“学员”**或**“同学”**，不用“客户”“买家”；
- 团队与学员的关系是**“陪伴”**，不用“转化”“私域运营”“跟进”；
- 拒绝互联网黑话（“赋能”“抓手”“闭环”“打法”），多用**“一起”“慢慢”“可以”“安顿”**。

---

## 6. 品牌禁忌红线清单 (Red Lines)

任何页面、海报、功能模块与文案上线前，必须逐项对照以下红线：

- [ ] ✕ **严禁出现轮播 Banner 广告、功能金刚区宫格、弹窗广告与悬浮广告球**；
- [ ] ✕ **严禁制造焦虑**：不出现倒计时器、库存紧张红字、已抢 XX 件、XX 人正在拼团；
- [ ] ✕ **严禁营销裂变诱导**：不出现“分享给好友领红包”“砍价免费拿”；
- [ ] ✕ **严禁游戏化内卷机制**：不搞等级排行榜、连续签到断签惩罚；
- [ ] ✕ **严禁使用高饱和度亮色、大红大橙渐变按钮与重度阴影投影**；
- [ ] ✕ **严禁使用低幼表情包插画或夸张卡通 IP**；
- [ ] ✕ **星点与印章严格限量**，绝不为了装饰而满屏堆砌；
- [ ] ✦ **核心自检标准**：
  1. *“这一屏 / 这一页，能不能再少一样东西？”*
  2. *“遮住 Logo 之后，这件作品是否仍然能让人一眼认出是若星，而不是市面上的任何一个普通电商或知识付费软件？”*
